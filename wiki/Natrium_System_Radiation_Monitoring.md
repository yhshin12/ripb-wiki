# Natrium Radiation Monitoring System (RMS)

> [!abstract] 요약
> Radiation Monitoring System(`RMS`)은 area, effluent, process 감시 그룹으로 이루어진 디지털 계통이며 Non-Safety-Related with Special Treatment%%t:NSRST%%와 Non-Safety-Related with No Special Treatment%%t:NST%% 기능을 가진다. `HAA`와 `SCG`의 방사능을 검출해 `UMC`·`AMC`로 신호를 보내 `DL4-RR1c`, `DL4-RR4a`, `DL4-RR4b`를 지원하고 Type C·F `PAM` 변수를 `RPS`로 보내지만, 자동 제어 동작은 하지 않는다.

## 해설
Radiation Monitoring System(`RMS`)은 NSRST%%t:NSRST%%와 NST%%t:NST%% 기능을 가진 디지털 계통으로, 발전소 전반의 계통·건물·방출 경로를 전략적 접점에서 감시한다. 선택된 방사성 공정의 연속 감시와 시료 분석, 방사성 유출물이 부지 경계를 벗어날 수 있는 방출점 감시를 수행하며, 연속 운전으로 작업자 피폭이 `10 CFR 20` 한계를 넘지 않도록 정보와 경고를 제공한다. 감시 그룹은 Area Radiation Monitoring(`ARM`), Effluent Radiation Monitor(`ERM`), Process Radiation Monitoring(`PRM`)의 셋이다. 설계상 액체 유출물이 없으므로 액체 유출물 감시기는 없다.

일부 감시기는 `IEEE 497-2016`의 Type C, D, E, F `PAM`으로 credit된다. Type C·F로 credit된 감시기 신호는 Digital Radiation Monitor System(`DRMS`)으로 가는 신호와 별도로 병렬 아날로그 신호로 `RPS`에 가고, Type D·E만으로 credit된 감시기는 `DRMS`로만 간다. NSRST%%t:NSRST%% 기능 감시기는 할당된 감시기와 직접 통신하는 독립·격리 `Radiation Indicator Controller`를 써서 `DRMS` 연결을 보완한다. Type C·F `PAM` 감시기는 NSRST%%t:NSRST%%로 분류되고, 그 controller는 `NCB` cabinet room이나 division별 `RPS` cabinet room에 있다.

`RMS`는 정상, Anticipated Operational Occurrence%%t:AOO%%, 사고 뒤, 보수 운전 동안 NSRST%%t:NSRST%% 기능을 지원할 수 있고, 각 계기의 설계 운전 조건은 감시 대상 계통·건물에 따라 정해진다. regulatory guide%%t:RG%% 부합은 `RG 1.21, Revision 3` 완전 부합, `RG 1.97, Revision 5` 부분 부합(범위는 operating license%%t:OL%% 단계에서 제공), NSRST%%t:NSRST%% 구성품의 `RG 1.100` 완전 부합이다. `RG 1.180`은 제목이 `Revision 2`인데 부합 문장은 `Revision 4`로 적혀 있다.

기능 표의 NSRST%%t:NSRST%% 기능은 가상 방출 뒤 `HAA HVAC` 운전(`DL4-RR1c`)과 `SCG` cell barrier%%t:BARRIER%% 격리 누설 검출(`DL4-RR4b`)을 위해 `UMC`로, `SCG` 격리 밸브 자동 닫힘(`DL4-RR4a`)을 위해 `AMC`로 방사능 신호를 보내는 것과, Type C·F `PAM` 변수 표시를 위해 `RPS`로 보내는 것(`DL5-PAM1`)이다. principal design criteria%%t:PDC%% 2에 따라 NSRST%%t:NSRST%% 구성품은 외부 재해를 견디도록 설계된 구조물에 있다. PDC%%t:PDC%% 13에 대해 원문은 `RMS`가 노심, primary coolant boundary의 safety-significant 요소, functional containment의 건전성을 알리는 방사선 정보를 제공하고 이 변수와 계통을 규정 운전 범위 안에 유지하는 control을 제공한다고 적는데, §7.6.6.3은 `RMS`가 자동 제어 동작을 제공하지 않는다고 적어 두 문장이 어긋난다. PDC%%t:PDC%% 60에서는 방사성폐기물 처리 계통의 방출 여유나 추가 처리 필요를 지시하는 감시 요소를, PDC%%t:PDC%% 64에서는 방사성 방출 가능성이 있는 `NI` 건물 대기, 소듐·cover gas 정화 공간, 유출물 방출 경로, 발전소 환경의 감시 수단을 제공한다.

감시기 성능 목표는 정상 운전부터 사고 뒤까지 포괄하는 계기 범위, 공칭 한계 초과를 지시하는 setpoint, 발전소 요건에 맞는 응답 시간이다. `RMS`는 자동 제어 동작을 하지 않으므로 setpoint는 `MCR` 지시와 국부·원격 경보만 일으킨다. programmatic special treatment는 Design Reliability Assurance Program, Equipment Qualification Program, Quality Assurance Program Description, Post-Construction Inspection, Testing, and Analysis Program으로 예비 식별되고, 규격 special treatment는 `IEEE 338-2022`, `IEEE 603-2018`, `IEEE 379-2014`, `IEEE 497-2016`이다. 구성품 지진 분류는 `SCN1`이다. 신뢰성 특성은 이중화 감시점, `NI Uninterruptible AC Power Supply System` 전원, 자기 시험, 품질 설계 과정이며, NSRST%%t:NSRST%% 감시기는 surveillance testing과 periodic calibration을 받는다. `HAA`와 `SCG` 감시점은 이중화 감시기로 구현되고, 통합 plant stack에는 전용 wide range gas monitor 두 대가 있으며, 이 전원 계통은 `HAA`·`SCG`의 NSRST%%t:NSRST%% 감시기에 72-hour battery backup을 제공한다. 원문은 사고 뒤 감시가 가상 방출 뒤 대응·완화에 쓰일 정보를 주므로 충분한 심층방어(Defense-in-Depth)%%t:DID%%에 필요하다고 적는다.

`PSAR` Chapter 1은 effluent radiation monitoring의 주 기능을 `off-site exposure`가 `10 CFR 20` 한계를 넘지 않게 보장하는 것으로 적고, Chapter 7은 `ERM`이 `personnel exposure`의 한계 준수를 보장한다고 적는다. Chapter 1은 세 감시 부류를 `three main subsystems`, Chapter 7은 `three main monitoring groups`라고 부른다.
