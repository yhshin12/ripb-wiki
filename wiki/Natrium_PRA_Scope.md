# Natrium PRA의 범위와 방법 (Natrium PRA Scope and Methodology)

> [!abstract] 요약
> Kemmerer Unit 1 PRA는 NEI 18-04 틀을 구현하도록 `ASME/ANS RA-S-1.4-2021`의 해당 요건에 따라 개발되며, construction permit%%t:CP%% 단계의 PRA Technical Adequacy%%t:PRA_TECH_ADEQUACY%%는 내부 사건 출력 운전·저출력 정지 PRA의 자체 평가로 확립되었다. operating license%%t:OL%% 신청 전에 full-scope peer review를 수행하며, PRA 결과와 그 활용은 여러 장에 나뉘어 제시된다.

## 해설
이 보고서는 NEI 18-04 틀을 구현하려면 기술적으로 적정한 PRA가 필요하다고 적고, PRA를 `ASME/ANS RA-S-1.4-2021`의 해당 요건에 따라, regulatory guide%%t:RG%% 1.233 Revision 0이 승인한 NEI 18-04 틀을 구현하도록 개발한다. CP%%t:CP%% 신청의 PRA Technical Adequacy%%t:PRA_TECH_ADEQUACY%%는 `NEI 20-09` 지침에 따라 내부 사건 출력 운전·저출력 정지 PRA를 자체 평가하고, 그 결과를 `DG-1404`의 supporting requirements와 비교해 확립했다. PRA 문서와 소프트웨어는 품질보증 프로그램을 따르는 형상 관리 과정에서 유지되고, 결과에 more-than-minor 영향이 있을 수 있는 가정은 따로 표로 정리되며, 평가 결과 CP%%t:CP%% 단계 PRA는 CP%%t:CP%% 단계 설계를 합리적으로 반영하고 차이의 영향은 작다고 판단했다. `Model Change Tracking` 과정은 PRA 기술, 입력 자료, 산업 경험, 발전소 성능의 변화도 감시한다. RG%%t:RG%% 1.247에 따라 OL%%t:OL%% 신청 전에 OL%%t:OL%% 설계를 반영한 full-scope peer review를 같은 표준과 `NEI 20-09`에 따라 수행할 것이다.

자체 평가가 검토한 PRA 요소는 Plant Operating State 분석부터 risk integration까지 열두 가지이다. PRA가 평가하는 방사성 핵종 선원은 Reactor Enclosure System(In-vessel Storage의 사용후핵연료 포함), primary Sodium Processing System과 Sodium Cover Gas System, intermediate Sodium Processing System, 기체 방사성 폐기물, Ex-Vessel Handling Machine, Ex-Vessel Storage Tank, 사용후핵연료 처리 설비, Spent Fuel Pool이다. 이 선원들은 노심, Reactor Enclosure System 안의 기기, 재장전 중 옮기는 노심 집합체, 사용후핵연료 처리 활동에 영향을 줄 수 있는 사건과, Exclusion Area Boundary%%t:EAB%%에서 `30-day` total effective dose equivalent 100 mrem을 넘는 방출을 낼 수 있는 선원을 식별해 포함했다. 단일 원자로 부지이므로 다중 원자로 시나리오는 적용되지 않는다.

Plant Operating State%%t:POS%% 범위는 방출 barrier%%t:BARRIER%%나 안전 기능 수행에 영향을 줄 수 있는 운전 변화에 초점을 두며, 선별로 제외된 POS%%t:POS%%는 없다. Initiating Event%%t:IE%% 식별은 LWR과 비경수형원전(non-light-water reactor)%%t:NON_LWR%%의 공개 목록에서 시작해 위 표의 non-LWR 설계 자료를 고려하고, `December 2022` 기준 Natrium event sequences 목록의 발전소 결함을 검토했다. 계통 선원이 EAB%%t:EAB%%에서 100 mrem을 넘는 선량을 낼 수 있는지는 소외 선량 해석으로 확인하고, IE%%t:IE%% 군별 빈도는 일반 자료와 설계 정보, fault tree 모델로 산출하며, 화학 재해는 모두 정성 선별하고 OL%%t:OL%% 단계에서 재평가한다. Event Sequence%%t:ES%% 분석은 POS%%t:POS%%, IE%%t:IE%%, 안전 기능, 계통 고장·성공의 조합 가운데 방출로 이어질 수 있는 것을 정하고, 각 event tree는 초기사건별로 시간 독립적인 계통 기반 응답을 준다. success criteria 분석은 방출 barrier%%t:BARRIER%% 손상을 막기 위해 만족해야 할 barrier%%t:BARRIER%%와 핵심 안전 기능의 기준을 정한다. 고장 추정은 모두 일반 산업 자료나 공학적 판단에 근거한다.

ES%%t:ES%%의 끝은 안전·안정 상태이거나 방사성 핵종 방출이며, 방출은 시점과 심각도가 비슷한 release categories로 묶인다. 각 범주에는 적절한 Mechanistic Source Term%%t:MST%%을 배정해 NEI 18-04 Task 7a와 7b에 필요한 방사선 결말을 계산한다. 정량화에는 `Phoenix Architect 2.0`과 `FTREX` Version 1.8을 쓰고, `UNCERT`로 Licensing Basis Event%%t:LBE%% 빈도의 5th와 95th percentile을 계산하며, 정량화 도구와 방법에 특정한 한계는 식별되지 않았다. CP%%t:CP%% 단계 PRA는 내부 사건 출력 운전과 저출력 정지만 다룬다. 이 보고서의 PRA 결과와 위험 통찰은 final safety analysis report의 것에 비해 예비적이며, `Chapter 3`은 PRA에서 도출된 LBE%%t:LBE%%를, `Chapter 4`는 통합 위험 결과와 NEI 18-04의 세 cumulative plant performance metrics 비교 및 심층방어(Defense-in-Depth)%%t:DID%% 적절성 평가를, `Chapter 5`는 risk-significant Structures, Systems, and Components%%t:SSC%%를, `Chapter 6`은 Safety-Related%%t:SR%%과 Non-Safety-Related with Special Treatment%%t:NSRST%% SSC%%t:SSC%%의 reliability·capability target을 다룬다.

결과에 more-than-minor 영향이 있을 수 있는 가정 표는 local core blockage의 IE%%t:IE%% 빈도를 1E-03 per year로 두고 오차 인자 10의 lognormal 분포를 가정하며, 일반 자료가 일곱 자릿수 범위에 걸쳐 그 중간을 골랐다고 적는다. 표에는 또 `NI Control System` 채널의 분기별 시험, 디지털 공통원인 인자 1E-04, Ex-Vessel Handling Machine 피동 냉각 고장률 1E-04 per demand, 원자로 헤드에서 head access area로의 누설률(헤드 격리 성공 시 하루 체적의 1%, 실패 시 100%)과 head access area에서 환경으로의 누설률(격리 성공 시 10%, 실패 시 100%)이 있다. 이 표는 head access area를 containment라고 부른다.

systems analysis는 ES%%t:ES%% 분석에서 event tree 정량화에 필요한 fault tree를 만들며, event tree의 각 top event에 필요한 frontline system과 그 기능을 뒷받침하는 support system을 다룬다. Human Reliability Analysis는 ES%%t:ES%%에 관여하는 인적 상호작용을 평가하고 그에 대응하는 human failure event의 확률을 추정한다.

**NRC staff 평가.** NRC staff는 사업자의 PRA 자체 평가를 PRA 품질을 평가하는 유용한 초기 도구로 보지만, "Met"로 평가된 supporting requirement에 대해서도 PRA의 적정성이나 수용성을 판단하는 데 자체 평가에만 의존하지 않는다고 적는다.

IE%%t:IE%%가 특정 인적오류로 생길 수 있는지는 IE%%t:IE%% 분석의 일부인 system review에서 평가한다.
